# GraphQL User API

Simple GraphQL API for managing users using Apollo Server and SQLite.

## Features
- Add new users (with email validation and unique email constraint)
- List all users
- Filter users by name or email
- Delete user

## Technologies
- Node.js
- Apollo Server
- GraphQL
- SQLite (better-sqlite3)

## How to run

1. Install dependencies:
npm install

2. Start server:
node index.js

3. Open in browser
http://localhost:4000
